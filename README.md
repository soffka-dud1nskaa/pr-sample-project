#JavaLab2
Лабораторная работа по Java.
##Структура проекта
Проект содержит задания №1–№8.
task1 — целочисленные ловушки
task2 — вещественная арифметика
task3 — побитовые операции
task4 — обработка текста
task5 — одномерные массивы
task6 — многомерные массивы
task7 — методы и аргументы
task8 — консольное меню
##Требования
Для работы необходима установленная Java.
Проверить Java можно командой:
java -version
